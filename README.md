## Overview

A shopping cart implementation built with PHP following Clean Architecture principles. This project demonstrates best practices in software design, including separation of concerns, dependency injection, and testability.

## Features

- Clean Architecture design pattern
- SOLID principles
- Unit tested
- Modular and maintainable codebase
